Partner API — v1

Generate videos from your own platform

If your product doesn't have a video-generation engine, AfriVid can be that engine. Send a topic and your preferred settings, get back a finished video — unbranded, ready to host inside your own product.

Get an API key instantly. No waiting on us — enter your details and a key is generated right here. Free tier is capped at 20 requests/month; contact us if you need more.

Authentication

Every request needs your API key in the X-API-Key header.

X-API-Key: your_api_key_here

Generate a video

POST https://afrivid-processor-222827815864.africa-south1.run.app/api/v1/generate-video

ParameterTypeDescription
topic one ofstringWhat the video should explain, e.g. "how compound interest works". AfriVid writes the full script from this. Mutually exclusive with script.
script one ofstringVerbatim mode. Your own finished narration text. AfriVid narrates it exactly as written — no AI writing, rewriting, paraphrasing, summarising or fact-adding of any kind happens to it. Use this when your copy is already reviewed or compliance-approved. The text is split into scenes deterministically: on markdown headers (#, ##, …) where present — the header becomes the scene's on-screen title and is not narrated — otherwise on sentence boundaries at roughly 45–70 words per scene. A sentence is never split. Mutually exclusive with topic; passing both, or neither, returns 400.
titlestringOptional. In script mode, adds an opening title card using this exact text. Also used as the video's title.
durationinteger (seconds)Target video length. Default 60. See Durations below for realistic ranges. Not applicable in script mode — it is ignored there, because the video has to be however long your text genuinely takes to narrate. Padding it out would mean inventing filler, and cutting it short would mean dropping your real content. Use the estimated_duration in the response to know the length upfront.
languagestringDefault "English". See Languages below.
voicestring"woman" or "man". Default "woman".
stylestringTone of the narration and visuals. See Styles below. Default "educational and informative".
contextstringOptional extra background to ground the script in — product details, specific facts to include, etc.

Example request:

curl -X POST https://afrivid-processor-222827815864.africa-south1.run.app/api/v1/generate-video \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "how compound interest works",
    "duration": 90,
    "language": "English",
    "voice": "woman",
    "style": "educational and informative"
  }'

Example request in verbatim script mode — your exact words, no AI writing:

curl -X POST https://afrivid-processor-222827815864.africa-south1.run.app/api/v1/generate-video \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Compound Interest Basics",
    "script": "## What Compound Interest Is\n\nCompound interest is the process by which interest earns further interest over time...\n\n## Why Time Matters\n\nBecause growth is exponential, the number of years invested matters more than the rate itself...",
    "language": "English",
    "voice": "woman"
  }'

Response (immediate — generation happens in the background):

{
  "accepted": true,
  "job_id": "api_1787920000",
  "status_url": "https://afrivid-tts.reaganayiecho.workers.dev/job-status/api_1787920000",
  "estimated_duration": 118,
  "scene_count": 5
}

estimated_duration is the total narration length in seconds, computed by summing the scenes. In script mode this is the real length your text will produce, so you know upfront what you are getting rather than having to wait for the render.

Check status

Poll the status_url from the response above every few seconds — no auth needed on this one, the job ID itself is the credential.

GET https://afrivid-tts.reaganayiecho.workers.dev/job-status/api_1787920000
{
  "job_id": "api_1787920000",
  "status": "processing",
  "progress": 65,
  "stage": "Rendering motion graphics...",
  "output_url": "",
  "thumbnail_url": ""
}

When status becomes "completed", output_url is a direct link to the finished MP4 — no AfriVid branding anywhere in the video, ready to host or embed in your own product. If it becomes "failed", stage explains why; just submit the request again.

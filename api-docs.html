AfriVid Studio API
Partner API — v1

Generate videos from your own platform

If your product doesn't have a video-generation engine, AfriVid can be that engine. Send a topic and your preferred settings, get back a finished video — unbranded, ready to host inside your own product.

Access is invite-only for now. Contact AfriVid Studio directly to get an API key. There's no self-serve signup or billing yet — that's coming later.

Authentication

Every request needs your API key in the X-API-Key header.

X-API-Key: your_api_key_here

Generate a video

POST https://afrivid-processor-222827815864.africa-south1.run.app/api/v1/generate-video

ParameterTypeDescription
topic requiredstringWhat the video should explain, e.g. "how compound interest works". AfriVid writes the full script from this.
durationinteger (seconds)Target video length. Default 60. See Durations below for realistic ranges.
languagestringDefault "English". See Languages below.
voicestring"woman" or "man". Default "woman".
stylestringTone of the narration and visuals. See Styles below. Default "educational and informative".
contextstringOptional extra background to ground the script in — product details, specific facts to include, etc.

Example request:

curl -X POST https://afrivid-processor-222827815864.africa-south1.run.app/api/v1/generate-video \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "how compound interest works",
    "duration": 90,
    "language": "English",
    "voice": "woman",
    "style": "educational and informative"
  }'

Response (immediate — generation happens in the background):

{
  "accepted": true,
  "job_id": "api_1787920000",
  "status_url": "https://afrivid-tts.reaganayiecho.workers.dev/job-status/api_1787920000"
}

Check status

Poll the status_url from the response above every few seconds — no auth needed on this one, the job ID itself is the credential.

GET https://afrivid-tts.reaganayiecho.workers.dev/job-status/api_1787920000
{
  "job_id": "api_1787920000",
  "status": "processing",
  "progress": 65,
  "stage": "Rendering motion graphics...",
  "output_url": "",
  "thumbnail_url": ""
}

When status becomes "completed", output_url is a direct link to the finished MP4 — no AfriVid branding anywhere in the video, ready to host or embed in your own product. If it becomes "failed", stage explains why; just submit the request again.
